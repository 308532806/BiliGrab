# BiliGrab 1.9.5

一句话：**设置面板在支持的系统上会用真实的「磨砂玻璃」——背后的内容被原生模糊；不支持的机型保持原样（高对比、不透明），没有任何回归。**

---

## 改了什么

### 按能力分档的玻璃质感

打开设置面板时先做一次能力检测：Android 12+，且系统的跨窗口模糊开关处于开启状态
（`WindowManager.isCrossWindowBlurEnabled()`）。

| | 支持的设备 | 不支持的设备 |
|---|---|---|
| 窗口模糊 | `setBackgroundBlurRadius(28dp)` | 不请求 |
| 面板网格底色 | `0x88`（更透，让磨砂透出来） | `0xF5`（高对比，保证可读） |
| 背景遮罩 dimAmount | `0.28` | `0.58` |

面板底色的开关是 `GlassMeshDrawable.backgroundAlpha(int)`：0..255 截断，
默认 255 —— 即不改变原有的不透明绘制。光斑与顶部渐变不受影响。

### 在「不支持模糊」的设备上实测无回归

本机（OPPO PDPM00 / Android 12，系统不支持跨窗口模糊）安装 1.9.5 复测：
主页玻璃网格、设置面板贴底与圆角、H.264 开关（52×28dp 药丸轨道 + 正圆滑块）
均与 1.9.4 一致。

## 下载与安装

见本页附件 `BiliGrab-1.9.5.apk`（versionCode 10905，minSdk 26）。

```powershell
adb install -r BiliGrab-1.9.5.apk
```

## ⚠️ 签名说明（重要）

| 版本 | 签名证书 SHA-256 前缀 |
|---|---|
| 1.9.0 / 1.9.1 | `5F:71:50:AA…`（原始密钥） |
| 1.9.2 / 1.9.3 | `2D:F9:DF:23…`（意外生成的新密钥） |
| **1.9.4 / 1.9.5** | `5F:71:50:AA…`（已回到原始密钥） |

- 从 **1.9.4**（以及 1.9.1 及更早的原始密钥版本）升级：直接覆盖安装即可；
- 从 **1.9.2 / 1.9.3** 升级：需要先卸载一次（签名不匹配，系统会拒绝覆盖安装；
  卸载会重置应用内设置，已下载到公共目录的文件不受影响）。
