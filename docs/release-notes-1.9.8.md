# BiliGrab 1.9.8

一句话：**视觉引擎只保留玻璃态（新拟态切换移除）；设置面板改为恒不透明；下载位置「选择目录 / 恢复默认」两键等高；内置 yt-dlp 更新到 2026.08.19。**

---

## 改了什么

### 视觉引擎收束为玻璃态单引擎

设置面板「外观」里曾有一行「视觉引擎」（新拟态 / 玻璃态）切换。两种风格共用同一套尺寸与动效参数，
只改变表面绘制，但对普通用户来说这个选项没有实际收益，还带来一个隐性成本：两条渲染路径都要维护、
都要测。本版直接收束为单引擎：

- 删除设置面板里的「视觉引擎」切换行与相关文案（`settings_skin` 等 4 条字符串资源同步移除）；
- `Prefs.getSkin()` 恒返 `SKIN_GLASS`、`HyperTheme.skin()` 恒定玻璃态（旧偏好字段与写入接口保留，便于兼容）；
- 设置面板的玻璃底色改为恒 100% 不透明（0xFF），窗口模糊仍用于磨砂观感与遮罩浓度分档；
- 文档（README / DESIGN / docs/DESIGN-SYSTEM.md）同步改写为「玻璃态单引擎」。

### 设置面板恒不透明

用户反馈「设置界面透明的影响观看」。1.9.7 曾把不透明度提到模糊可用 78% / 无模糊 100%，
本版进一步收紧：**无论系统模糊是否可用，面板底色恒为 100% 不透明**，彻底杜绝背后内容透上来的可能。
毛玻璃观感仍由 28dp 背景模糊 + 网格光斑 + 描边承担。

### 下载位置按钮等高

下载设置里「选择目录」与「恢复默认」两个按钮高度不一致（一个按紧凑按钮样式、一个按默认按钮样式）。
本版为「恢复默认」补上与「选择目录」一致的紧凑按钮样式（布局高度与最小高度同为
`@dimen/button_height_compact` = 48dp），两者视觉重量对齐。

### 内置 yt-dlp 更新到 2026.08.19

`scripts/fetch-vendor.ps1` 新增 `$YtDlpVersion` 参数与下载步骤：拉取 yt-dlp 本体并校验 `#!` 头后
覆盖 `vendor/res/raw/ytdlp`；CI 缓存 key 同步更新（`…-ytdlp-2026.08.19-v2`），确保流水线拿到新版。
本版 APK 内置的 yt-dlp 为 2026.08.19（3,072,469 字节，sha256 `1fa6733c…`，
已从发布产物 `res/raw/ytdlp` 解包比对一致）。

## 下载与安装

见本页附件 `BiliGrab-1.9.8.apk`（versionCode 10908，minSdk 26）。

```powershell
adb install -r BiliGrab-1.9.8.apk
```

| 版本 | 签名证书 SHA-256 前缀 |
|---|---|
| 1.9.0 / 1.9.1 | `5F:71:50:AA…`（原始密钥） |
| 1.9.2 / 1.9.3 | `2D:F9:DF:23…`（意外生成的新密钥） |
| **1.9.4 / 1.9.5 / 1.9.6 / 1.9.7 / 1.9.8** | `5F:71:50:AA…`（已回到原始密钥） |

- 从 **1.9.4 ~ 1.9.7**（以及 1.9.1 及更早的原始密钥版本）升级：直接覆盖安装即可；
- 从 **1.9.2 / 1.9.3** 升级：需要先卸载一次（签名不匹配，系统会拒绝覆盖安装；
  卸载会重置应用内设置，已下载到公共目录的文件不受影响）。
