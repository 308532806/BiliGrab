# BiliGrab 1.9.7

一句话：**设置面板不再透底——面板必须挡住后面的内容；主页「解析」按钮与上方视频链接卡片之间补上 16dp 间距。**

---

## 改了什么

### 设置面板透底修复（反馈：透明影响观看）

玻璃面板此前为了透出磨砂感，整体不透明度定得偏低：窗口模糊可用时 53%（0x88），
系统关闭模糊时 96%（0xF5）。结果是面板后面的 URL 输入框、提示文字笔画会隐约透上来，
阅读面板内容时被干扰。

本版把面板底色收紧到「以遮挡为前提」：

| 系统能力 | 改前 | 改后 |
|---|---|---|
| 窗口模糊可用（Android 12+ 且跨窗口模糊开启） | 53% 不透明度 | **78%（0xC8）**，保留一点透感但文字不再穿透 |
| 系统关闭模糊 | 96% 不透明度 | **100% 全不透明（0xFF）**，彻底杜绝透底 |

磨砂观感仍由 28dp 背景模糊 + 网格光斑承担，面板圆角、贴底、色卡等均不受影响。

真机对照（OPPO PDPM00 / Android 12）用 5 倍对比拉伸复核：旧版可在面板区域看到
输入框与提示文字的笔画残影，新版面板区域干净平整。

### 主页「解析」按钮间距修复

「解析」主按钮此前紧贴上方视频链接卡片下缘，两种状态切换时边缘看起来像连在一起。
本版在按钮上方补 space_lg（16dp）间距，与页面其它区块间距同一节奏。

真机几何核对：按钮 bounds 由 [72,717][1008,897] 变为 [72,765][1008,945]，
与卡片间距由 0 变为 48px（= 16dp，480dpi 下换算）。

### H.264 开关复核（延续 1.9.6 审核结论）

跟随本次改动在真机复核：深色模式 OFF 渲染正常、关闭面板重开保持 OFF（持久化），
浅色模式 ON 正常，复核后恢复夜间设置。


## ⚠️ 签名说明（重要）

| 版本 | 签名证书 SHA-256 前缀 |
|---|---|
| 1.9.0 / 1.9.1 | 5F:71:50:AA…（原始密钥） |
| 1.9.2 / 1.9.3 | 2D:F9:DF:23…（意外生成的新密钥） |
| **1.9.4 / 1.9.5 / 1.9.6 / 1.9.7** | 5F:71:50:AA…（已回到原始密钥） |

从 **1.9.4 ~ 1.9.6**（以及 1.9.1 及更早的原始密钥版本）升级：直接覆盖安装即可；
从 **1.9.2 / 1.9.3** 升级：需要先卸载一次（签名不匹配，系统会拒绝覆盖安装；
卸载会重置应用内设置，已下载到公共目录的文件不受影响）。
