# BiliGrab 1.9.6

一句话：**六处遗留绘制并入玻璃体系 —— 登录页补上玻璃外框并把网页裁进圆角、骨架屏与药丸改用玻璃引擎画法、进度条槽不再消失；发布前完成 H.264 开关真机审核。**

---

## 改了什么

### 玻璃统一：六处遗留绘制并入玻璃体系

1.9.5 之后，应用里还留着几处“穿帮”的旧绘制 —— 颜色或形状跟玻璃体系对不上。本版全部并入：

| 位置 | 改前 | 改后 |
|---|---|---|
| 解析结果药丸（主页面） | 半透明色叠在旧页面底色上 | 引擎「主色面」通路：主色打底 + 玻璃描边（与设置面板色卡同一画法） |
| 骨架屏占位块（主页面） | `divider` 冷灰实色，叠在暖白玻璃上发脏 | 凹面玻璃色（浅色 4% 黑 / 深色 12% 白），保持低对比 |
| 进度条槽（主页面 / 下载管理页） | `divider` 冷灰，玻璃态下几乎不可见 | 新增 `HyperTheme.progressTrack()`：中性叠色（浅色 10% 黑 / 深色 12% 白） |
| 登录页 WebView 外框 | 方角，加载空窗期四角露白 | 玻璃外框（28dp 圆角，与 `radius_card` 一致） |
| WebView 圆角裁剪 | 没有 outline，`clipToOutline` 裁不动 | `NeumorphicDrawable.getOutline()` 把圆角轮廓交给系统 |
| 登录页白底兜底 | 网页就绪后刷白会盖掉玻璃外框 | 玻璃态下不再刷白（网页自身有白底，无需兜底） |

### H.264 开关真机审核

设置界面的 H.264 开关在 1.9.6 上完成真机复审（OPPO PDPM00 / Android 12 / 480dpi）：

- **几何**：轨道 52×28dp 圆角药丸 + 22dp 回形滑块 —— 与设计一致；
- **主题**：深色 / 浅色两套下描边、填充与滑块均正常；
- **持久化**：关 → 关闭设置面板 → 重开 = OFF；开 → 关闭面板 → 重开 = ON。
  （仅在关闭面板时落盘是既有设计 `setOnDismissListener`，非回归。）

### 真机复测

主页、设置、下载管理、登录页截图复核通过：玻璃网格、面板贴底与圆角、
登录页四角裁剪、骨架屏玻璃态均正常，无回归。安装为覆盖安装（未卸载），
未触发签名冲突。
